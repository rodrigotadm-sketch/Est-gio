Arquivos:
- index.html
- styles.css
- app.js
- estagios.json

PUBLICAÇÃO
1. Crie um repositório público, por exemplo Estagios-Biomedicina.
2. Envie os quatro arquivos para a raiz.
3. Ative GitHub Pages em main / (root).
4. Incorpore a URL no WordPress da UFPR por iframe.

ATUALIZAÇÃO SEMESTRAL
Edite principalmente estagios.json:
- semester
- semester_orientation
- responsáveis por modalidade
- documentos e URLs
- orientações específicas
- contatos
- carga horária, caso o PPC seja alterado

Fontes institucionais usadas:
- Página de Estágios do Curso de Biomedicina
- UE/COAPPE/PROGRAP
- Perguntas Frequentes da Unidade de Estágios
- PPC do Curso de Biomedicina
